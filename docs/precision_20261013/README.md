# 精度這條線：依位置決定 KV 精度，有沒有用？（2026-10-13 起）

**一句話**：先在 3090 上用兩個模型量「全 BF16」和「正確校準的全 FP8」兩個端點（外加「只保護 sink」的全 FP8）。全 FP8 就夠，就往下一階用 INT4 再量一次；兩階都夠就停。找到「均勻不夠」的那一階，才比「25% 低精度放前段／後段／隨機」（sink 一律保留 BF16），並逐 block 記錄「重算／載入 BF16／載入低精度」，把「不敏感」和「沒被讀到」分開。

**狀態**：計劃（還沒跑任何東西）。這一頁取代 [CORE_QUESTION_20261008](../CORE_QUESTION_20261008.md) 的「寫入時依位置放哪一層」，當作新的核心問題。第一階段的結論（放置可以延後）不變，見 [phase1 13 號報告](../phase1_20261008/13_advisor_update_20261012.md)。

## 核心問題（只有一個）

> 在同樣的品質要求、同樣的資源（存的位元組、頻寬、GPU 可用度）下，**依位置決定哪些 block 用 FP8**，會不會比「全 FP8」或「同比例隨機放」更好？

用老師的筆記比喻：筆記 64 頁，回來時小明（GPU）從第 1 頁往後重抄，快遞（I/O）從倉庫把最後一頁往前送，兩人在中間碰頭。現在有 16 頁改用「縮印版」（FP8）存。
- 縮印的如果是**前面**幾頁：小明反正會重抄，縮印版根本沒人看。品質不會掉，但也沒有變快。
- 縮印的如果是**後面**幾頁：快遞一定會送到，縮印版送得快，但字比較糊，答案可能看錯。
- 小明很忙時（GPU 忙），兩人碰頭的地方往前移，前面的縮印版也開始被用到。

所以「前段量化沒掉品質」可能只是**沒被讀到**，不是**不敏感**。這週的實驗就是要把這兩件事分開。

## 這版自己決定的設計（核心合理就不先問老師；10/20 報告時明講）

1. **兩個模型都跑端點，再照事先寫好的表選主模型**：Llama-3.1-8B（代表性）和 Qwen2.5-7B-1M（Key 怕量化的壓力測試）。不用九月的舊資料選，因為那批實驗題目太簡單、題數太少、情境不同、有混雜（[03 §1.1](03_plan_3090.md#11-模型兩個模型都跑端點再照規則選主模型)、[05 §3](05_QA.md#3-llama-全部-2020是不是實驗設計有問題)）。
2. **精度階梯 FP8 → INT4**：FP8 這一階不需要位置策略，就往下一階 INT4 再看一次；INT4 也不需要就整個停。只走一階、事先寫死。**這和老師「全 FP8 過就停」不同**，理由：混精度只在「均勻低精度不夠」的地方才有意義，FP8 可能還沒到那裡（[03 §2.5](03_plan_3090.md#25-精度階梯fp8-不需要就往下一階最多一階)）。
3. **停損 K3**：全 FP8 不過時，先換 codec 試（K 減掉固定偏移再存 FP8、或全 INT8）。任一個過了，就是格式的問題，不是位置的問題（[02 §5](02_papers.md#5-vllm-的-fp8怎樣才算正確校準)）。
4. **混合配置一律把 block 0（sink 所在）留成 BF16**，另加 E1s 單獨量 sink（[03 §2.1](03_plan_3090.md#21-六個配置)）。
5. **題目難度**：每個模型、任務族、位置帶的 BF16 正確率都要在 60–95%，不碰天花板；品質要求 ε＝2 個百分點，780 題（[03 §3.2](03_plan_3090.md#32-題數與難度)）。
6. **只用 GQA 模型，不改 MHA**：頻寬用「會合點落在哪」來選，相對比較不受 KV 大小影響；MHA 留到之後當穩健性檢查（[03 §1.1](03_plan_3090.md#11-模型兩個模型都跑端點再照規則選主模型)）。
7. **格式在每一階內固定**：這週只動「位置」一個變數。
