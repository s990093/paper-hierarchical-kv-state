零件都有人做，組起來的沒找到

有人在 LLM 上做過潛空間測試時搜尋（Soft Reasoning、LatentSeek、LTPO、LTO），也有人做過推理用的潛世界模型（Thoughts-as-Planning、CoLA）。但「凍結 base＋小 predictor 想像＋CEM＋MPC」這整套，本次沒找到。查不到不等於沒有。

最大的問題
LLM 的「執行一步」很便宜

機器人動一下又貴又不能退回，所以要先想像。LLM 跑一個候選步只要一次 prefill，還能從 KV 分叉。H＝1 時，想像出來的狀態比不上免費拿到的真實狀態，世界模型等於白做。

建議主線
方向 A：文字先、潛未來 MPC

第 1 步取 LLM 產生的 N 個真候選。第 2…H 步在學出來的 8–32 維潛動作上做 CEM（對應 V-JEPA 2-AC 的 7 維動作），由 20–60M 的 predictor 想像、value 打分。base 不動，任何開源模型都能外掛。

怎麼驗證
K1 → K2 → K3 三道停損關

K1 看 hidden state 裡有沒有對錯訊號，K2 看想像能不能贏過直接 value，K3 看同計算量下贏不贏。等 MI300X 租約 10/23 結束後在 3090 上跑，不搶 Tiara 的佇列。

關鍵推論 〔判讀〕

value head 是用 base policy 的蒙地卡羅結果訓練的，所以 V(zk+1) 本身就在估「照 base policy 走下去會答對的機率」。如果世界模型只是照同一個 policy 往下想像，在期望值上就跟 value head 重複。它要有用，只能靠兩種機制：

  • 機制 (a) 搜尋未來動作：取 max over a₂…aH，而不是照 base policy 的期望。這需要便宜的潛動作。
  • 機制 (b) 表徵學習：把「預測下一個狀態」當輔助目標，讓 value 更準、更省資料。

PoC 的 K2b 會把這兩種機制分開測。

原計劃要改的地方

六個要改的地方（P5、P6 是讀全文後新增的）

P1
問題CEM 開在 896–4096 維上：動作是步驟向量。在這種維度上抽出來的點會落在流形外，value head 會被鑽漏洞（假高分）。V-JEPA 2-AC 的動作只有 7 維。
改法用逆動力學 ak＝g(zk, zk+1) 學出 8–32 維的潛動作，CEM 只在這上面搜尋。初始分佈取經驗分佈，並限制在 L1 球內（照 V-JEPA 2-AC 的作法）。
P2
問題LLM 的「執行」很便宜：第 1 步做 prefill 就能免費拿到真實的 zk+1，H＝1 的想像沒有意義。soft token 寫回凍結 LLM 也會分佈外（Coconut 要訓練才行）。
改法第 1 步一律是 LLM 產生的真文字，想像只用在第 2…H 步。H＝1 改成對照組：步驟 beam 搭配 V(真實 zk+1)。soft token 降為選配。
P3
問題EMA／stop-grad 是多的：V-JEPA 2-AC 第二階段本來就凍結 encoder。目標是凍結 LLM 的 hidden state 時，目標固定，不會崩塌。
改法刪掉「EMA 開／關」這個消融，改成監控 predictor 輸出的方差，並一律跟 copy、線性 baseline 比。E2（goal predictor）有循環論證的問題，降為選配。
P4
問題計算優勢要算過才成立：照搬 800×10 的 CEM 預算時，7.6B base、H＝4 的 FLOPs 是 39.6，比文字前瞻的 32 還貴。0.5B base 即使 CEM 降到 64×5，也只省 1.16 倍。
改法CEM 降到約 64 樣本 × 5 輪。主實驗用 1.5B／7B 以上的 base，0.5B 只做煙霧測試。見下方 計算量。
P5
問題連續潛動作可能學到捷徑：CoLA 刻意改用離散 codebook（N＝64），理由是連續潛動作容易只學到下一步的資訊、忽略更大的脈絡〔原文 p.16〕。
改法列成 PoC 消融：連續 8–32 維 vs CoLA 式離散 codebook。
P6
問題value 會被鑽漏洞，一般模型的探針校準差：LTO 說獎勵模型不完美時，最佳化會去鑽它的錯〔原文 p.7〕；探針論文中 Llama-3.1-8B-Instruct 的 AUC 0.82 跟推理模型的 0.86 差不多，但 ECE 是 0.23 對 0.03〔原文 p.6〕。
改法能量只用來排序、不當機率門檻；加 KL／不確定度懲罰；K1 同時在 R1-Distill 推理模型上跑。

方法 A 的一個決策週期

文字先、潛未來：每一步怎麼選

虛框 凍結，不訓練 赭橘 文字空間，真的生成 靛藍 潛空間，可訓練的小模型 琥珀 打分

訓練目標（base 全程凍結）

  • Ltf：teacher forcing，‖P(z≤k, a≤k) − zk+1‖₁
  • Lro：2 步 rollout，照 V-JEPA 2-AC 的作法
  • Linv：逆動力學，搭配 8–32 維瓶頸。這是讓 CEM 可行的關鍵
  • Lvalue：BCE，正確與錯誤的軌跡都用
  • 不需要 EMA：目標是凍結的 hidden state

防止規劃器鑽 predictor 的漏洞

  • 潛動作限制在經驗分佈的 L1 球內（V-JEPA 2-AC 用的半徑是 0.075）
  • 用 3–5 個 predictor 組成 ensemble，把彼此的不一致度加進能量當懲罰
  • 評估時一律對照蒙地卡羅真值（K2b），不只看 L1 誤差
計算量 〔算術〕

H＝1 沒有優勢；V-JEPA 2-AC 的 CEM 預算不能照搬

單位是「解碼一個候選步驟」，約 2·Nbase·L FLOPs。設定：N＝8 個候選、每步 L＝40 token、predictor 50M、base 7.6B。方向 A 的成本 ＝ N ＋ N·S·(H−1)·u，其中 S 是每個候選的 CEM 樣本數，u ＝ Npred/(Nbase·L) ＝ 1.64×10⁻⁴。這是 FLOPs 近似，wall-clock 沒有量（NOT_MEASURED）。

方向 C 的具體版本 〔判讀〕

test-time search 同時保留 N 個分支的 KV。value head 會預測「這個分支之後還會不會被展開」，這可以直接當成 Tiara 動作空間 {GPU-BF16, FP8, INT4, CPU, SSD, DROP＋重算} 的放置訊號：低 value 的分支降精度或丟掉。這是 Tiara「在品質約束下、各動作成本不同」的同一個框架，換到搜尋情境來用。

P0 資料

取樣、切步、抽 hidden

1.5B 模型；GSM8K train 2,000 題 × 8 次取樣，test 1,319 題。抽 4 個層的步驟邊界 hidden state。

過：載入斷言「步驟 token 數總和＝整條長度」全部成立（規則 6）不過：停下回報
K1 訊號

hidden state 有沒有對錯訊號

按題目切 train／val，用線性探針從 zk 預測最終對錯。

過：軌跡中段 AUC ≥ 0.70不過（< 0.60）：E1 能量不可行，轉 B／C
K2a 健全性

predictor 有沒有學到東西

跟 copy baseline（ẑk+1＝zk）、線性 baseline 比 L1 誤差。

過：L1 ≤ copy 的 0.8 倍不過：回頭檢查切步方式與選的層
K2b 想像

想像比直接 value 好嗎

300 個前綴 × 8 個候選，每個續寫 8 次估真實 value。比 Spearman ρ：V(真實 zk+1)、H＝2／4 的 CEM 分數、接 predictor 特徵的 value。

過：後兩者任一比 V(真實) 高 ≥ ＋0.05不過：世界模型多餘，寫成負面結果，主線轉 C
K3 同計算量

端到端贏不贏

GSM8K test 上比 greedy、SC@{4,8,16}、BoN＋探針、步驟 beam＋V(真實)、PRM beam、A（H＝2／4），報準確率對生成 token、FLOPs、KV 峰值、wall-clock。

過：至少一個預算點勝過步驟 beam＋V(真實) ≥ 1.0 pt，且 95% CI 不跨 0不過：NO-GO，結果寫成分析
RQ3

失敗軌跡有沒有用

predictor 與 value 分別只用正確軌跡、或正確加錯誤軌跡訓練，用 K2b 的指標比。
