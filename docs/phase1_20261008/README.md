## 最關鍵的一組比較

**S4+（延後寫入＋成本感知）vs S5（寫入時依位置放）**

兩者在空間不夠時做法完全一樣，只差在「寫入當下」那一步，所以這組的差距就是「寫入當下就決定」的淨價值。拿 S5 和最好的簡單策略比，判讀方式是：
- 差距 < 5%：簡單策略追平；
- 5–15%：找老師判斷；
- \> 15%：進第二階段。

詳見 `01` §3、`03` §4、`05` §6。
