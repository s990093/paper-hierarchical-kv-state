# 01 老師的要求，以及我們怎麼做

> **一句話**：老師要求用兩週做一個小而完整的驗證。下表把老師的每一句話對應到這個資料夾裡的做法。

---

## 1. 老師 10/7 的回覆（原文）

> 兩邊不用一起做，先把 sys-level 這條線跑完整，我覺得這樣比較好。HTCS 你先不用急著接。
>
> 這次你有把自己的方法可能沒有效果的情況也列出來，這個很好。願意先看現有方法實際怎麼跑，再判斷自己的想法值不值得做，後面的實驗才比較容易找出真正的問題。
>
> 各篇模型、硬體和 workload 不同，確實很難說誰是唯一的 SOTA。但最接近你方法的幾篇，還是要放在公平的設定下比較。研究最後要回答的是：現有方法哪裡做不好？你的做法改善多少，或多做到什麼？這個不能只靠文獻表判斷。
>
> 像你現在想的「寫入時先不存前段 KV」，我想確認的是，省下的寫入到底有沒有縮短等待？Cake 本來就會重算前段、載入後段，所以少存不一定讓下一次還原更快。而且如果那時 GPU 很忙，沒存的部分還是得重算。你要把省下的 I/O 跟增加的計算一起看，也要跟延後寫入、成本感知逐出比較。
>
> 另外，我覺得這條線可以保留往 CVPR 做的可能，不一定要換掉 sys-level 的方向。你可以在探索裡選一個真正的視覺情境，像長影片持續累積 KV，或同一份多頁文件反覆被詢問，看看現有方法在固定 memory 和延遲限制下，究竟卡在哪裡。CVPR 已經有像 MuKV 這類研究，可以看看它怎麼把 cache 問題和視覺任務接起來。但只換成 VLM 跑一次，還不夠說明貢獻。
>
> **你先用兩週做一個小而完整的驗證。選一台能穩定使用的機器、一個模型，把最接近的 baseline 跑通，確認實際 I/O 路徑，再量同一設定重跑會波動多少。先固定精度和還原方式，比較「先寫再丟」「一開始不寫」以及合理的延後寫入，看看差別到底來自哪裡。預測器、量化和 500K 先放後面。**
>
> 兩週後給我看能重跑的結果，還有一張能解釋時間花在哪裡的比較圖。我們再一起判斷，這個改善是不是強 baseline 還做不到，能不能收斂成 CVPR 的問題。只省空間也可以，但要確認它真的解決了有用的限制；如果簡單策略就追平，我們就知道應該調整哪裡，不用繼續花時間把整套架構做大。
>
> CVPR 2027 是 11/10 AoE 註冊、11/16 AoE 正文截稿，時間有點緊，我們先看這兩週的證據，再決定要不要爭取。中間設備或 baseline 卡住就直接找我討論，不用等全部弄完才來。

## 3. 改成「每段都存」之後，老師的疑問還剩哪些

老師那段話是針對我原本的設計「寫入時先不存前段」。現在的設計改成「每段都存，只在寫入時依位置決定每段的狀態」。第一階段只有 CPU、SSD 兩種狀態，所以變成「預期會被搬的後段放 CPU，其餘放 SSD 當備份」（`02` §6）。所以老師的四個疑問裡，有兩個不成立了，兩個還在：

| 老師說的 | 現在還成立嗎 | 為什麼 | 在哪裡量 |
|:--|:--|:--|:--|
| 少存不一定讓下一次還原更快 | **不成立** | 現在沒有少存，每段都存了一份。<br>但換成一個新問題：「後段放 CPU」有沒有讓還原變快，要和純 Cake 比 | A1：S5 vs S0 |
| GPU 很忙時，沒存的部分還是得重算 | **不成立** | 前段在 SSD 有備份。GPU 忙時，會合點可以往前移，改從 SSD 搬，不用硬算 | A1：仍保留 S3（一開始不寫），用來量「如果刪掉」要付多少 |
| 省下的 I/O 要跟增加的計算一起看 | **換個形式還在** | 現在不是省下 I/O，而是**多寫**了前段：每段都寫進 SSD，但 GPU 閒時前段的備份根本不會被讀到，等於白寫。<br>要量的是：這些多寫的 I/O 會不會擋到別人從 SSD 讀資料 | A2；B 的寫入量 |
| 要跟延後寫入、成本感知逐出比 | **還在，而且變成最主要的問題** | 延後寫入＋成本感知（S4+）在 CPU 放不下時，會先把前段降到 SSD，最後也變成「後段在 CPU、前段在 SSD」，和我的放法一樣 | B：**S4+ vs S5** |

**為什麼最後一點最重要**：S4+ 和我的方法（S5）最後的擺法一樣，只差在什麼時候把前段寫進 SSD。
- **我的方法**：一開始就寫。
- **延後寫入**：等 CPU 快滿了才寫。如果使用者沒回來，或 CPU 一直夠用，就一次都不用寫。

所以要回答老師的，其實是這一句：

> **「一開始就放好」，比「等快滿了再搬」好嗎？好多少？**

如果量出來延後寫入追平我的做法，就照實記錄，並找出原因（`05` §6）。

**實驗設計不用因此改。** 老師點名的「先寫再丟」「一開始不寫」仍然要跑：它們用來說明「刪掉前段」的代價，也就是我為什麼改成每段都存。
