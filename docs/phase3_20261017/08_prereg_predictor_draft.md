## 1. 問題與決策介面（和 07 §2.2 相同，換成真實的格式表與外層做法）

- 每個 session 在 D1、D2 各選一次格式；格式與品質照 `results/p3_formats/format_table.json`（Llama：BF16、fp8_token、int4_kivi、int2_kivi；Qwen 的 8-bit 用 int8_token，04 §1）。品質過關＝`quality_verdict_32k` 為 PASS；>32K 的 INT4 算未驗證（不過）；INT2 只能給不會再被讀的。
- 成本＝寫入與讀取的位元組（CPU、SSD；04 §4 的主指標是 SSD 的寫＋讀，另報含 CPU 的版本）＋λ × S × 1[讀到不過關的格式]。
- D2 的時刻由外層做法決定（04 §2 的 E1–E6，E5 的 T＝5、30、60 分）：同一個預測器在每個外層做法下各算一次 regret。
- 分數 → 動作：分數 ≥ θ1 → 最小過關格式，否則 INT2；D2 分數 < θ2 → INT2。θ 在 valid 上挑。
- **要先在 08 凍結前決定的**：如果真實版加入「依回來時間選精度」的動作（例如快回來的留 BF16、因為反量化慢；04 §3 的「最省」若包含還原時間），介面就不只兩個動作，07 的「LRB 式補值沒輸」要重新檢驗。

## 5. 判讀規則（草稿）

- 「預測器有用」（每個外層做法、每份資料分開判）：最好的預測器（含整體退路）的 regret 相對 LRU 規則的配對差，以 session bootstrap 的 95% CI 上界 < 0，而且相對省 ≥ 5%（04 §6 的 NO-GO 門檻）。
- 「某個家族有用」：F0＋該家族相對 F0 的配對差 CI 上界 < 0；「拿掉會傷」：全部 vs 全部減該家族的 CI 下界 > 0。
- 「F4 值得擴大」：見 §0。
- 「比較穩」：照 07 §2.9（各資料、各外層做法都和最好的打平，且最差的格子不比 LRU 差 >1%）。
- 不准事後換主指標、λ、門檻挑法；改了要記在 §8。

## 6. 從合成資料帶來的風險（07 的教訓）

1. D2 的正例極少 → D2 自己訓練的模型過擬合；優先「D1 訓練＋條件化」或 LAVA 式擴增（07 §4.1）。
2. 大樹過擬合 → 先用小樹與 LR（07 §4.3）。
3. 門檻要在 valid 上挑；罰得重（λ＝16）時，valid 上挑的門檻也會讓模型在線索弱時比 LRU 差 2% → 整體退路必做（07 §4.5）。
4. 增益集中在「多數不回來」的工作負載（合成資料 π＝0.9 時 −18%、π＝0.3 時 −1%）；FreeInference 的設限只有 1.1%（03b §3.1），很可能落在「增益小」的一端〔判讀〕。
5. 合成資料的特徵消融不代表真實資料（07 §4.4）；弱的歷史線索（AUC ≈ 0.6）單獨推不動 λ＝4 的門檻，只在和強線索一起時多 ~1 pp。
6. 分數出現 NaN 時，「s ≥ θ」是 False，會**靜默變成全部壓成 INT2**（07 §6 第 4 點）；真實資料的管線要把 NaN 當錯誤、整個方法不進評估（規則 7）。
